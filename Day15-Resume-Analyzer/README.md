# Day 15 - Resume Analyzer

Final project concept.

## Flow
1. User uploads a resume.
2. React frontend sends the request to the Node.js/Express backend.
3. Backend processes the resume.
4. Skills are identified and matched against the selected role/job description.
5. The application calculates/displays skill matching, job matching percentage and ATS score.
6. Results are returned to the React frontend.

## Technologies
- HTML
- CSS
- JavaScript
- React
- Node.js
- Express
- MongoDB/Mongoose
