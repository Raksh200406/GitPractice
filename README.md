# MERN Stack - 15 Day Practice

This repository contains a 15-day MERN Stack learning and practice track.

## Topics
1. HTML Basics
2. HTML Forms & CSS Flexbox
3. JavaScript Basics
4. JavaScript Arrays & Objects
5. DOM & Events
6. Responsive CSS
7. JavaScript ES6
8. React Basics
9. React Props & State
10. React Forms & API
11. Node.js
12. Express.js
13. MongoDB & Mongoose
14. Frontend-Backend Integration
15. Resume Analyzer
